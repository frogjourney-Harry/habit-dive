# 公開服務的資料與權利處理流程

日期：2026-11-13。維護者：Harry（Frog Journey）。這是給維護者的執行清單，不是法律意見或免責條款；沒有設定自動寄信、刪資料或外部通報。

## 已核對的事實

- 2026-11-13 維護者確認 Firestore 地區為 `asia-east1`；官方地區表對應台灣。不是從私人 Firebase 設定、玩家資料或管理金鑰取得。
- Firebase 官方說明 Authentication 在美國處理；不能把 Firestore 的台灣地區說成全部資料都在台灣。
- 既有 Google Forms 回報表單以未登入的只讀 HTTP 請求回應200，含「其他」、問題說明及選填聯絡 Email；未填寫、提交或查看任何回覆。可作資料權利／素材疑義的聯絡入口。
- 現有程式提供下載備份、編輯紀錄、登出、重新驗證後刪除雲端紀錄與 Firebase 帳號；刪除不會移除 Google 帳號，也不清掉各裝置的本機副本。
- 雲端同步以上傳前交易檢查避免直接蓋掉另一台新版本；仍不是逐項合併。前端備份不代表伺服器存在可回溯的所有歷史版本。
- 維護者於2026-11-13確認：正式 Firestore 規則與專案 `firestore.rules` 相同。該規則要求登入且 `request.auth.uid == uid`，只允許使用者存取自己的 `users/{uid}` 文件，其他路徑沒有授權。此項為維護者在控制台確認，不是 Codex 直接登入或執行正式端存取測試；IAM、備份與保留設定未另行核對。

## 一、資料權利申請

1. 收到表單後記錄收件日、請求種類、聯絡方式、狀態與決定日期。只留處理所必要的資訊，不另收密碼、驗證碼、證件或整份玩家備份。
2. 資料僅在玩家裝置時，說明維護者無法從雲端取回，提供遊戲內查看、修改、備份與瀏覽器清除方式。
3. 帳號相關請求先核對身分及範圍；優先引導以原 Google 帳號登入，使用既有匯出／刪除功能。**不得只憑表單填的 UID、Email 或「我是帳號主人」就提供資料、改帳號或刪資料。**需要其他確認方式時採必要、相稱的方法；無法確認時說明原因並保留處理紀錄。
4. 依台灣個資法第13條，查詢、閱覽、複製本請求的准駁決定原則上15日內；必要時延長不得逾15日並書面通知原因。更正、停止或刪除等第11條請求原則上30日內決定；必要時延長不得逾30日並書面通知原因。這是決定期限，不是宣稱所有技術備份必於當天完全消失；個案按適用法規處理。
5. 涉及停止利用或刪除時，說明登出只停止本裝置同步，其他裝置可能重新上傳；提醒玩家登出其他裝置、確認雲端刪除完成，再自行處理各裝置本機資料。部分失敗應告知現況，不能只回覆「已刪除」。
6. 結案時檢查回報內容及副本是否仍有保存必要；無必要者刪除或去識別化。依法需留存的案件紀錄另標示依據及範圍，不無限期保留整份私人紀錄。

## 二、資料遺失／同步錯誤

1. 請玩家先保留現有紀錄並自行下載備份，不要先清瀏覽器、反覆還原或在多台同時操作。
2. 只索取去識別化的錯誤描述、版本、裝置、操作時間與同步狀態。診斷不含帳號或清單，不能靠診斷直接重建私人紀錄。
3. 先分辨本機儲存失敗、尚未同步、帳號不同、版本衝突或刪除／還原操作；無法確認時不要替使用者覆蓋其中一台進度。
4. 說明目前可恢復的範圍及限制；不能承諾找回沒有任何可用副本的資料，也不能以免責文字取代依法應負的責任。

## 三、素材／權利疑義

1. 收集權利人或代理人的必要聯絡資訊、作品／頁面網址、遊戲中被指涉內容及具體疑義。不要要求公開完整原作品或無關身分資料。
2. 核對 [素材清冊](asset-provenance.md)、現行圖稿指紋、引用來源與原始生成／修改紀錄。工具是 Claude 或 AI 生成，不等於已取得所有第三方授權。
3. 有可信且具體的疑義時，評估暫時停用或換圖；涉及真實權利爭議時取得法律協助。不未查即斷言侵權，也不以「沒有收到投訴」當成無侵權證據。
4. 保留最小必要的處理紀錄與更正版本；不透過重寫 Git 宣稱過去利用行為或第三方快取從未存在。

## 四、安全事故與發布維護

- 若疑似資料被未授權存取，先限制影響、保留必要證據、確認受影響資料與帳號；依事故時適用法規處理通知／通報，不只改隱私頁文字。
- 正式 Firestore 規則已由維護者確認與專案一致；後續變更時需重新核對，避免誤用測試用開放規則。這不等於 IAM、管理端存取、備份與正式刪除流程也完成獨立實測。
- 發布只加入明確檔案，排除備份、玩家資料、本機預覽與審查封包。SDK、資料使用目的、地區或保存做法變動時，同步更新隱私與授權。
- 本次沒有設定自動保存期限、啟用後端備份、調整雲端地區或操作正式 Firebase。文件中的必要期間刪除，需要維護者實際執行，不能只停留在文字。
