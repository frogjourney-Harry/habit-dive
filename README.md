# 習慣深潛

像素風的習慣養成遊戲。每天寫下最重要的事，完成就賺金幣、在商店開寶箱收集水下生物、從浮潛客一路升級成潛水教練。

- 📝 每天最多六件最重要的事，前三件完成有金幣，點編號可以換順序
- 🎯 每日任務：完成的事情到這裡領金幣和 XP，忘了領隔天自動入帳
- 🍅 番茄鐘工作階段，中間自動安排休息
- ✍️ 為 Vocus 創作者設計：記錄發布篇數，連勝節奏自己決定
- 🐠 20 種水下生物，各有幼體、成體和特殊型態
- 🐟 水族箱：餵食你養的生物，看牠們長大
- 🛍 獎勵商店自己設定

## 資料與隱私

預設所有資料只存在你自己的瀏覽器（localStorage），不會上傳到任何伺服器。換裝置或清除瀏覽資料會遺失紀錄，請定期在「紀錄」頁備份。

也可以選擇用 Google 登入，紀錄會同步到 Firebase（Firestore），換裝置也能接續。只取用名稱和 email；資料庫規則（`firestore.rules`）限制每個人只能讀寫自己的資料；登入後可隨時刪除雲端資料和帳號。沒登入的人不會載入任何 Firebase 程式。

本工具為個人作品，與方格子 vocus 官方無關。

## 使用

直接開啟網站即可，不需要註冊或登入。

## 檔案結構

純靜態網站，沒有建置步驟；`js/` 裡是一般的 script，依 `index.html` 的順序載入、共用全域變數。

| 檔案 | 內容 |
|---|---|
| `index.html` | 頁面骨架 |
| `css/style.css` | 所有樣式（手機版放在最後） |
| `js/config.js` | 可調整的數值、內建習慣、稀有度、等級稱號 |
| `js/creatures.js` | 像素圖、生物資料、三種成長型態與顏色 |
| `js/core.js` | 日期、存檔與資料轉換、狀態推導、音效 |
| `js/game.js` | 寶箱與獎勵、番茄鐘、彈窗 |
| `js/views.js` | 各個頁面的畫面 |
| `js/firebase-config.js` | Firebase 網頁設定（公開資訊，安全靠資料庫規則） |
| `js/sync.js` | 選擇性的 Google 登入與雲端同步 |
| `js/main.js` | 按鈕與輸入事件、啟動 |
| `firestore.rules` | Firestore 安全規則：只能讀寫自己的資料 |
| `bump.sh` | 推上線前執行，更新 index.html 裡的版本號，避免瀏覽器用到舊的快取 |
| `img/` | 網頁圖示（瀏覽器分頁、iPhone 加到主畫面） |
| `tests/` | 自動測驗（見下） |

## 自動測驗

`tests/index.html` 是一套在瀏覽器裡跑的測驗：每個測驗都在獨立的 iframe 載入真正的網頁（獨立儲存、可調的假時鐘、假的 Firebase 雲端），用真實的點擊操作，並且會檢查元素有沒有被別的東西蓋住。涵蓋每日流程、獎勵上限、換日與週期、番茄鐘、寶箱與商店、水族箱、舊版資料遷移與壞存檔、備份匯入匯出、兩個分頁同開、雲端同步（含斷線與多裝置）、環境差異（沒有音效引擎、無痕模式、App 內建瀏覽器、舊瀏覽器語法）、各種螢幕寬度的版面、無障礙，以及隨機亂點加不變量檢查。

在本機用任一靜態伺服器開啟專案資料夾，再打開 `/tests/index.html?auto` 即可；`?run=關鍵字` 只跑符合的測驗，`?seeds=1-20&steps=300` 調整亂點的組數與步數。
